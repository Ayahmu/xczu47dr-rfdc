# TDC Constraints

The build loads `tdc_placement.xdc` and `tdc_timing.xdc` through
`hardware/vivado/scripts/target_config.tcl`.  `tdc_placement.xdc` is the
2048-tap placement of the delivered design; it is generated by
`hardware/vivado/scripts/generate_tdc_capture_xdc.py` and a test keeps the two
in step.
