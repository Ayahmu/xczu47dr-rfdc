# 硬件验收

本文只记录需要仪器确认的项目。驱动测试通过，只能说明 UDP、寄存器和播放状态机
走通，不能代替本验收。

## 1. 固定配置

| 项目 | 当前设计值 |
| --- | --- |
| 外部参考 | XS17，250 MHz（本分支） |
| HMC7044 DAC 参考 | 128 MHz |
| DAC 采样率 | 6.4 GS/s |
| 插值 | 16 倍 |
| RFDC 复数输入 | 400 MS/s |
| AXIS/fabric 时钟 | 50 MHz |
| DDR 布局 | `interleaved_512b` |
| 输出映射 | CH1/2/3/4/5/6/7/8 -> `vout00/02/10/12/20/22/30/32` |

## 2. 上电前检查

- 两块板的 XS17 来自同一个 250 MHz 参考源；示波器时间基准尽量使用同一参考。
- 连接好电源、JTAG、串口和 10G 网络；双板同步按“主 XS20 -> 从 XS20、主 XS18 -> 从 XS19”。
- RF 输出接合适的差分探头或转换器，并按仪器要求加入衰减器、隔直器和 50 欧端接。
- 记录板卡编号、bitstream/ELF SHA256、线缆和衰减值、示波器带宽/采样率/触发设置。

## 3. 数字启动验收

1. 烧写匹配的 bitstream 和 ELF，串口 115200 观察启动日志。
2. 确认 HMC7044 配置完成，RFDC PLL、DAC MTS、NCO SYSREF 均就绪。
3. 用 `dr47-network status` 确认 RFCTRL2 在线、通道能力正确、网络 IP 唯一。
4. 执行单板测试，确认 `ARM -> TRIGGER -> RUNNING/DONE -> ABORT_MUTE` 状态完整。
5. 双板测试中确认从卡 `sync_seen=True`、`sync_link_ready=True`，每次物理 Trigger
   的输入和接受计数各增加一次。

## 4. 双板确定性同步与 ILA 验收

### 4.1 确定性 SYNC 原理

当前 RTL 已把主卡的 SYNC 上升沿重定时到 HMC7044 回传的 10 MHz monitor 时钟
(`mclk_10m`)，而不是在 PS PL_CLK0 异步时钟域里直接拉高。因为 `mclk_10m` 与
HMC7044 的 VCXO/VCO 相位确定，所以每次 `SyncGroup.sync()` 都会把 HMC7044 输出
分频器 reseed 到相同的 VCO 相位，预期结果是每次上电/烧写后主从两路 RF 输出相位差
固定，标定一次补偿即可持续使用。

数字链路可重复性用 `hardware_master_slave_deterministic_sync_test` 验证：连续多轮
`sync -> ARM -> trigger`，确认主从 `sync_alignment_epoch` 稳定递增，且 DAC MTS、
NCO SYSREF、`sync_link_ready` 都完成。真正的 RF 相位是否固定必须用示波器同时观察
两块板卡的 CH1/vout00（50Ω 端接）确认；数字状态通过不等于相位已经达到某个数值。

### 4.2 ILA 数据路径验收

历史故障曾出现 `top_i/dac_ch1_valid_gated=1` 但 RFDC 输入端
`top_i/dac_in_ch1_tdata` 一直是 `0x00010000...` 常数。用
`software/ila_gaussian_capture.py` 在 ILA 里确认主卡播放 0 Hz 基带高斯包络时，
`top_i/rfdc_ch1_tdata` 呈现“先为零 -> 高斯包络 -> 再回零”，而不是恒定值。

注意 ILA 触发源必须用 `top_i/pc_started`。旧的 `pc_trig_start` 只由 GPIO/RVCTRL
路径产生；RFCTRL2 软件 `trigger()` 走 `rfctrl2_trigger` 路径，直接把 `started`
拉高，不产生 `trig_start`，用 `pc_trig_start` 永远抓不到 RFCTRL2 播放。

## 5. 模拟输出项目

对每个需要验收的 DAC 通道，至少记录以下结果：

| 项目 | 方法 | 记录 |
| --- | --- | --- |
| 频率准确度 | 频谱仪读取主峰，逐点改变 NCO | 设定值、实测值、误差 |
| 幅度线性 | 多档幅度测量平均功率/峰值 | 设定值、实测值、线性误差 |
| 波形包络 | 示波器观察高斯正弦的起止和宽度 | 延迟、持续时间、过冲 |
| 通道时序 | 多通道同时输出，测量边沿差 | 通道对、时间偏移 |
| 杂散和镜像 | 频谱仪扫宽带和目标带宽 | 主峰、镜像、杂散、噪声底 |
| 重复触发 | 连续触发并开启余晖 | 触发抖动、丢波次数 |

验收阈值由项目指标另行填写；没有阈值的项目先记录首轮实测基线，不要把“脚本成功”
当成模拟指标合格。

## 6. 250 MHz 参考异常排查

如果所有测得频率约为设定值的 `15/16`，优先检查 DAC 参考是否实际为 120 MHz，
而不是 128 MHz。重点检查：

- HMC7044 寄存器 `0x0003` 的高 VCO 选择；
- `0x0021` 的 `R1=1`；
- `0x0026` 的 `N1=10`；
- XS17 输入幅度、复位极性和 PLL lock 状态。

确认参考时钟前不要修改软件频率换算公式。频率共参考只能减少长期漂移，不能代替
对 HMC7044、RFDC、线缆和示波器本身的检查。
