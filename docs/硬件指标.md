# 硬件指标

本页列出应用开发和系统集成需要关注的接口特性。存储器布局、BRAM 数量等实现细节
不作为对外接口。

- 外部参考时钟为 XS17 的 250 MHz；波形接口的 RFDC fabric/AXIS 时钟为 50 MHz。
- DAC 模拟输出采样率为 6.4 GS/s；每个通道接收 400 MS/s 的复数 IQ 数据（I、Q 各 16 bit）。
- 插值：RFDC 使用 16x 插值，`400 MS/s x 16 = 6.4 GS/s`；目标 RF 频率由 NCO 与 Nyquist zone 共同设置。
- 波形输入格式：小端有符号 `int16` 交错序列 `I0,Q0,I1,Q1,...`；多通道按物理通道分别上传，长度以 RFDC beat 计数。
- 波形上传：100G 批量通路实测 91.6 Gb/s（约 11.5 GB/s），整片 8 GiB DDR4 约 0.75 s 传完；小波形和旧驱动仍可用逐包应答方式（约 12.9 MB/s）。详见 [API 接口参考](API参考.md) 的“批量上传”。
- 幅度：输出强度只由波形样点幅度决定（满幅 32767）；DAC 输出级固定，驱动不提供调节接口。
- 长度不超过 256 个 RFDC beat 的波形会在 ARM 阶段预取，Trigger 到来后直接重放。
- 更长的波形使用双缓冲；下一缓冲未准备好时，Trigger 会被拒绝并计数，不会延迟到稍后播放。
- 外部 Trigger 在 DAC 时钟域采样。接受后只引入一个 20 ns 时钟边界量化和 RFDC 固有流水线延迟；未满足播放条件的事件会立即记录为拒绝。
- 主卡输出同步信号，从卡接收同步信号；网络接口用于配置、发现和状态读取。

DDR 布局、BRAM 实现等内部细节不属于用户接口保证。
