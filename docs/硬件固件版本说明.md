# 硬件与固件版本说明

## 版本 1（`a7d65c83d94996b2667c3d7b41880f32934b0226`，2026-09）

- 建立 RFCTRL2 驱动 SDK 发布流程与主/从板目标配置。
- 统一网络发现、外部 Trigger 示例和软件触发示例。
- 完善构建目标、生产配置和文档结构。

## 版本 2（`97f18680bcadd914a5c82e80bbb746d20ac70a79`，2026-09）

- Trigger 播放路径改为 DAC 域直接接受与启动，移除旧延迟调度器。
- 增加 replay cache，短波形重复 Trigger 不再等待 DDR refill。
- 增加 RFCTRL2 诊断状态、错误计数和跨时钟域快照接口。
- 修复外部 Trigger 延迟逐次增加及周期性抖动相关路径问题。
- 生产工件精简为 XSA/ELF；XSA 内嵌 bitstream 与 `psu_init.tcl`。
- 移除旧 `dac_trigger_scheduler`、`TARGET_DAC_DELAY_CYCLES` 及 trigout/TDC 临时产物。

硬件和固件必须使用同一版本的 XSA 与 ELF，不支持跨版本混用。
