# 47DR 软件版本说明

## 发布信息

当前驱动版本为 `47dr-driver 0.1.0`，RFCTRL2 协议版本为 v3，支持 Python 3.10+
和 `numpy>=1.23`。软件版本与硬件/固件版本必须匹配；驱动默认校验板卡的协议、
build profile 和 Trigger path version。

## 变更记录

### 第一版：SDK 发布基础（`a7d65c83d94996b2667c3d7b41880f32934b0226`）

- 建立可发布的 Python SDK、wheel 和示例程序。
- 增加网络发现/配置、主从同步、软件 Trigger、外部 Trigger 和模拟器流程。
- 统一波形工具、有限 burst 调度和通道配置 API。
- 整理文档、测试目标和发布包校验清单。

### API 概览

完整签名、参数约束、返回值和示例见 [API 接口参考](API参考.md)。常用接口如下：

| 类别 | 接口 | 作用 | 主要参数 |
| --- | --- | --- | --- |
| 连接 | `Dr47Device`、`connect()` | 创建并连接板卡 | IP、端口、网卡、角色 |
| 网络 | `discover_boards()` | 广播发现板卡 | 网卡、源 IP、广播地址 |
| 网络 | `provision_board()` | 设置固定 IP/MAC | 目标 IP、MAC、网关 |
| 状态 | `status()`、`capabilities` | 读取连接、RFDC、同步和播放状态 | `refresh` |
| RFDC | `set_xy_target_frequency()` | 根据目标 RF 频率计算 NCO 和 Nyquist zone | 通道、GHz、DAC 采样率 |
| RFDC | `set_xy_nco_frequency()` | 直接设置 NCO | 通道、NCO GHz |
| RFDC | `set_gain()` | 设置输出增益/电流 | 类型、通道、数值、单位 |
| RFDC | `set_qc_on_off()` | 打开或关闭输出通道 | 类型、通道、`on/off` |
| RFDC | `commit()` | 提交暂存的 RFDC 配置 | 无 |
| 波形 | `configure_playback()` | 上传波形并创建播放配置 | 通道波形、`BurstSchedule`、格式 |
| 播放 | `arm_playback()`、`trigger_playback()`、`abort_playback()` | ARM、软件 Trigger、停止 | 通道掩码、run ID |
| 波形工具 | `make_iq_sine_interleaved()`、`make_iq_gaussian_sine_interleaved()` | 生成 IQ 波形 | 频率、幅度、采样率、时长 |
| 同步 | `set_sync_mode()`、`bypass_sync()`、`sync()` | 设置同步门控或执行主从同步 | 模式、epoch |
| Trigger | `emit_trigger()` | 从 XS18 输出 Trigger | 无 |
| 诊断 | `read_diagnostics()`、`clear_diagnostics()` | 读取/清除硬件快照和计数器 | 事件掩码、是否清计数 |

### 第二版：触发链路和诊断改进（`97f18680bcadd914a5c82e80bbb746d20ac70a79`）

- 增加 RFCTRL2 v3 诊断快照 API：`read_diagnostics()` 和 `clear_diagnostics()`。
- HELLO/STATUS 增加 build identity、Trigger path version 和播放计数器校验。
- RFDC busy 时重复配置会先停止播放并重试，减少 `0x0006` 对应用的干扰。
- XSA 成为硬件交付入口；SDK 和板卡产物不再依赖独立 bitstream/LTX 文件。
- 删除未交付的 TDC 公共 API，避免安装包暴露不支持的功能。

## 安装

源码开发环境：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r software/requirements.txt
python -m pip install -e software/dr47
```

发布包由仓库根目录生成：

```bash
make driver-release
python -m pip install dist/47dr_driver-0.1.0-py3-none-any.whl
```

SDK ZIP 包含 wheel、本文档、示例和校验清单；安装后可运行：

```bash
python -m dr47.examples.simulator_quickstart
```

## API

### 连接和状态

```python
from dr47 import Dr47Device, connect, discover_boards, connect_discovered

device = Dr47Device(ip="192.168.1.128", port=1234,
                    udp_interface="enp1s0f0", udp_source_ip="192.168.1.10",
                    sync_role="slave")
device.connect()                 # -> protocol version
status = device.status()         # DeviceStatus
caps = device.capabilities       # DeviceCapabilities
device.close()
```

连接相关函数包括 `connect()`、`discover_boards()`、`connect_discovered()`、
`provision_board()`、`prepare_interface()`、`parse_ip_pool()`。

### RFDC 和播放

```python
import numpy as np
from dr47 import Dr47Device, BurstSchedule

iq = np.zeros(1024, dtype="<i2")  # I0,Q0,I1,Q1,...
with Dr47Device(ip="192.168.1.128", batch_mode=True) as device:
    device.set_xy_target_frequency(1, 4.0)
    device.set_gain("xy", 1, 0.7, gain_type="norm")
    device.set_qc_on_off("xy", 1, "on")
    device.commit()
    cfg = device.configure_playback(
        {1: iq}, BurstSchedule(first_delay_ns=0, interval_ns=1000, repetitions=3),
        wave_formats={1: "interleaved_iq"},
    )
    device.arm_playback(cfg.channel_mask)
    device.trigger_playback()
    device.abort_playback()
```

RFDC 方法：`set_xy_target_frequency()`、`set_xy_nco_frequency()`、`set_gain()`、
`set_qc_on_off()`、`set_qr_on_off()`、`apply_rfdc_config()`、`commit()`、
`rfctrl2_rfdc_get_config()`。

播放方法：`configure_playback()`、`upload_waveforms()`、`arm_playback()`、
`trigger_playback()`、`abort_playback()`；兼容别名为 `arm()`、`trigger()`、
`abort_mute()`。`BurstSchedule(first_delay_ns, interval_ns, repetitions)` 的时间
按 20 ns DAC 域时钟向上量化，`first_delay_ns=0` 不插入软件延迟。

### 同步、Trigger 和诊断

同步方法：`set_sync_mode("external"|"bypass")`、`bypass_sync()`、
`require_external_sync()`、`sync(epoch=...)`、`emit_trigger()`；双板使用
`SyncGroup(master, slave).sync()`。

诊断信息：

```python
snapshot = device.read_diagnostics()       # DiagnosticsSnapshot
device.clear_diagnostics(events=0xFFFFFFFF, counters=True)
```

快照提供 Trigger 输入、接受、跳过和拒绝计数，以及 capture、launch、playback 时间戳、
replay/FIFO/underflow、RFDC/DMA/refill 状态和故障地址。普通程序使用 `status()`；
诊断只在定位时延或硬件故障时读取。

### 波形工具

`make_iq_sine_interleaved()`、`make_iq_gaussian_sine_interleaved()`、
`place_interleaved_iq_in_record()`、`make_burst_record()`、
`ezq_wave_to_interleaved_int16()`、`iter_interleaved_udp_waveform_packets()` 和
`iter_interleaved_udp_bulk_packets()` 用于生成或上传波形。

## 板级使用

生产烧写入口为 `./software/load_and_verify.sh slave`（或 `master`）。脚本从对应
XSA 提取内嵌 bitstream 和 `psu_init.tcl`，不需要独立 `.bit` 或 `_psu_init.tcl`。
外部 Trigger 示例为 `software/dr47/examples/hardware_slave_bypass_external_trigger_test.py`。
硬件接线和运行边界见[硬件指标](硬件指标.md)；硬件/固件变更见[硬件固件版本说明](硬件固件版本说明.md)。

## 支持范围

支持板卡发现、网络配置、RFDC 频率/增益/通道控制、CH1-CH8 波形、有限 burst、
软件和 XS19 外部 Trigger、主从 SYNC 及内存模拟器。不支持 TDC 校准/补偿公共 API，
也不能用软件测试替代示波器和频谱仪验收。
