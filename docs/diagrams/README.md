# XCZU47DR 单板波形系统 — DrawIO 图集

> 数据来源与《系统架构与性能定量分析.md》一致：RTL 源码 + `build/audit/impl_signoff_250mhz_20260920/` 签核报告。
> 仅保留 `.drawio` 原生可编辑文件（不导出 PNG）。

| 文件 | 内容 | 要点 |
|---|---|---|
| `01_整体架构图` | 系统级架构：外部/板级、控制面(300M)、AXI+DDR4、回放通路(50M)、TDC 链、时钟同步 | 写路径 Host→10G→DDR4；读路径 DDR4→8×FIFO→RF-DAC；TDC 补偿旁路 |
| `02_模块分解图` | 全部模块按 4 组分解（控制面 / 回放通路 / TDC 链 / 时钟外设） | playback_path 内部 8 个子模块；DSP 集中于紫区 ≈2304 |
| `03_模块交互图` | 时序图：①上传路径（慢）②回放路径（快）③确定性触发补偿（旁路） | 14 步消息流，含位宽与时延标注 |
| `04_时钟域图` | 6 个时钟域（2400.96M/300.12M/161M/156.25M/100M/50M/200M）与 3 个异步 CDC 边界 | 4:1 MMCM 相位对齐、25:48 周期比（20ns 抖动根因） |
| `05_触发延迟Breakdown` | raw 模式 vs 确定性模式触发→RF 输出延迟分解 | raw 0–40ns + 20ns 抖动；确定性 640ns 调度 + 200ns FIR/旋转，抖动数十 ps |
| `06_带宽瓶颈分析` | 回放通路带宽瀑布与瓶颈标注 | 12.8 GB/s 需求 / 19.2 GB/s 峰值 = 66.7% 唯一硬瓶颈 |

## 使用方式

- 编辑：用 draw.io 桌面版或 https://app.diagrams.net 打开 `.drawio`
- 命令行再导出：`drawio -x -f png -e -b 10 -o out.png in.drawio`
