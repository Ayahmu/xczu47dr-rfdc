 # 网页控制台部署说明

 网页控制台由 Vue 3 前端和 FastAPI 后端组成，适合在实验室内网使用。当前一次只
 控制一块板；双板同步请运行 dr47/examples 下的专用脚本。

 ## 安装

 下面假定仓库位于 /opt/xczu47dr-rfdc，服务状态放在 /var/lib/rfsoc-web：

 ~~~bash
 sudo useradd --system --home /var/lib/rfsoc-web --create-home   --shell /usr/sbin/nologin rfsoc-web
 sudo usermod -aG dialout rfsoc-web
 sudo mkdir -p /var/lib/rfsoc-web /etc/rfsoc-web
 sudo chown -R rfsoc-web:rfsoc-web /var/lib/rfsoc-web

 cd /opt/xczu47dr-rfdc
 python3 -m venv .venv
 .venv/bin/pip install -r software/requirements.txt
 cd software/webui
 npm ci
 npm run build
 ~~~

 复制并编辑环境文件，然后安装仓库中的 systemd 单元：

 ~~~bash
 sudo install -m 0640 -o root -g rfsoc-web   deploy/rfsoc-web.env.example /etc/rfsoc-web/rfsoc-web.env
 sudo editor /etc/rfsoc-web/rfsoc-web.env
 sudo install -m 0644 deploy/systemd/hw-server.service /etc/systemd/system/
 sudo install -m 0644 deploy/systemd/rfsoc-web.service /etc/systemd/system/
 sudo systemctl daemon-reload
 sudo systemctl enable --now hw-server.service rfsoc-web.service
 ~~~

 服务账号需要 dialout 组才能读取串口；JTAG 访问权限由 Xilinx udev 规则决定。
 修改组权限后要重启服务。

 ## 第一次登录和扫描

 1. 打开 http://服务器地址:8000，用环境文件中的管理员账号登录。
 2. 在网络扫描页面选择连接板卡的 10G 网口，确认扫描能收到 RFCTRL2 的 UID。
 3. 为板卡登记标签、JTAG 序列号和串口路径；没有 RFCTRL2 UID 的设备不会被加入。
 4. 获取板卡租约后先做 Dry Run，再执行上传、ARM、Trigger 和停止/静音。
 5. 只在单板数字链路验证通过后关闭仿真模式。

 网络扫描会配置候选网口并发送广播，systemd 服务需要 CAP_NET_ADMIN 和
 CAP_NET_RAW。若扫描停在网卡阶段，先检查服务权限和交换机 VLAN。

 ## 运行参数

 | 变量 | 默认值 | 用途 |
 | --- | --- | --- |
 | RFSOC_WEB_RUNTIME_DIR | ~/.local/state/xczu47dr-rfdc | 数据库、运行记录和发布文件 |
 | RFSOC_WEB_SIMULATION | 0 | 设为 1 时不访问真实板卡 |
 | RFSOC_WEB_ADMIN_USERNAME | admin | 空数据库首次创建的管理员名 |
 | RFSOC_WEB_ADMIN_PASSWORD | admin12345 | 首次管理员密码，部署时必须修改 |
 | RFSOC_WEB_COOKIE_SECURE | 0 | HTTPS 部署时设为 1 |
 | RFSOC_WEB_XSCT_BIN | Xilinx XSCT 路径 | 临时 JTAG 部署所用工具 |
 | RFSOC_WEB_PROGRAM_TIMEOUT_S | 900 | JTAG 部署超时 |
 | RFSOC_WEB_SERIAL_RECONNECT_S | 3 | 串口断开后的重连间隔 |

 ## 安全和备份

 服务只适合可信实验室网络。不要把 8000 端口直接暴露到互联网，必要时绑定内网
 地址或放在反向代理后面。定期备份 runtime 目录中的 SQLite 数据库、runs 和
 artifacts。网页的 JTAG 部署是临时下载，不会写 QSPI、SD 或 eMMC；串口接口只读。

 查看服务日志：

 ~~~bash
 journalctl -u hw-server.service -u rfsoc-web.service -f
 ~~~
